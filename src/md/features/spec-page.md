# Feature: Home Page

The home page gives the full suggestion on one page.

## Behavior

- The page is at `/`.
- The logo is `docs/srcmd.svg`. The page shows it next to the title and uses it as the favicon.
- The title is `/src/md/` as inline SVG outlines of Berkeley Mono Bold. The site does not ship the font.
- The page shows what, why, the suggested layout, content, workflows, and extensions.
- The page says that the Markdown is not a formal specification or documentation.
- The page links to the source essay: https://htmx.org/essays/markdown-in-src/
- The page links to this project's `src/md` as an example.
